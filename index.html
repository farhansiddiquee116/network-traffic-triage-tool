How to Think Like a SOC Analyst

Standard Network Triage Workflow

  1. Observe unusual behaviour Identify hosts deviating from normal packet volume, unusual protocol spikes, periodic beaconing, or atypical destination counts.
  2. Identify the source and destination Determine who is initiating communication and where the requests are landing (internal subnet vs. public Internet).
  3. Determine which protocol is involved Is it web traffic (HTTP/HTTPS), resolution (DNS), control messages (ICMP), or raw transport (TCP/UDP)?
  4. Establish whether the activity is expected Check system roles. A corporate file server is expected to push gigabytes; an office receptionist PC is not.
  5. Look for supporting indicators Are there regular periodic heartbeats (C2 Beaconing)? Are there high-entropy DNS subdomains (DNS Tunneling)?
  6. Correlate with other security telemetry & MITRE ATT&CK Cross-reference firewall logs, EDR process executions, or authentication audits from the suspected host.
  7. Decide whether further investigation is required Document your findings. Export a professional SOC Incident Triage Report for escalation or case closure.
“An anomaly is a starting point for investigation, not proof of compromise.”

Exporting Packets in Wireshark

Follow these 5 steps to generate compatible CSV files:

  1. Open Wireshark and select your active network adapter.
  2. Capture traffic in an authorised environment (e.g., your home lab).
  3. Stop the capture when done (red square button).
  4. Navigate to: File → Export Packet Dissections → As CSV...
  5. Save the file and upload it into this triage tool.

Analyst Limitations to Keep in Mind

  • Metadata vs. Full PCAP: CSV exports contain summary headers, not raw payload hex streams.
  • Encrypted Payloads: TLS/HTTPS traffic is encrypted; content cannot be inspected without decryption keys.
  • NAT Masking: Network Address Translation can cause an entire office or home to appear as a single public IP.
  • Static vs. Dynamic Thresholds: Real enterprise SIEMs calculate rolling statistical baselines rather than static numbers.
